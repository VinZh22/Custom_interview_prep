# Math

Quant and tech interviews lean on a small set of tools used flexibly. Aim for recall
speed on the checklists below, then drill problems.

## Folders

- [probability/](probability/) — conditional probability, Bayes, expectation tricks, common
  distributions, random walks, Markov chains, order statistics.
- [statistics/](statistics/) — estimators, bias/variance, MLE, CLT, hypothesis tests,
  confidence intervals, regression theory.
- [linear-algebra/](linear-algebra/) — rank, eigen/SVD, projections, positive definiteness,
  least squares, matrix calculus.
- [calculus-optimization/](calculus-optimization/) — series, integration tricks, Taylor,
  Lagrange multipliers, convexity, KKT.
- [combinatorics/](combinatorics/) — counting, inclusion–exclusion, pigeonhole, generating
  functions, recurrences.
- [brainteasers/](brainteasers/) — puzzles with no fixed syllabus: weighing, pirates,
  hat problems, invariants, parity arguments.

## Core techniques worth having reflexive

- Condition on the first step (recursion for expectations, random walks).
- Symmetry and indicator variables instead of summation.
- Linearity of expectation before anything clever.
- Law of total expectation/variance; tower property.
- Wald / optional stopping for gambler's-ruin shapes.
- Change of variables and the Jacobian for transformed densities.
- Invariants and parity for puzzle-style questions.
