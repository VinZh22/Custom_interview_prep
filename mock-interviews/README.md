# Mock interviews

Timed, out loud, no pausing to look things up — the point is to rehearse performing, not
solving. Write up every session, even the bad ones, using
[../templates/mock-interview.md](../templates/mock-interview.md).

Name files `YYYY-MM-DD-format.md`, e.g. `2026-08-03-quant-phone-screen.md`.

## Session formats

| Format | Length | Contents |
| --- | --- | --- |
| Coding screen | 45 min | 1 medium + 1 follow-up, narrated |
| Quant phone screen | 30 min | mental math, 2 probability, 1 market-making game |
| DS case | 45 min | one open prompt + metric follow-ups |
| ML/stats theory | 30 min | rapid-fire derivations |
| Behavioral loop | 30 min | 4 prompts, 2 min each, no notes |

## Rules

- Timer visible. Stop when it goes off, even mid-solution — then note where you were.
- Talk continuously. Silence is the most common real-interview failure.
- No editing the write-up to look better afterwards.
